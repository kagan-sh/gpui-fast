# Published GPUI Fast crates

These are the `0.1.14` crates from crates.io, as published, for the eight packages kagan patches: `gpui-fast`, `gpui-fast-apple`, `gpui-fast-macos`, `gpui-fast-platform`, `gpui-fast-linux`, `gpui-fast-wgpu`, `gpui-fast-web`, `gpui-fast-macros`.

Kagan's `[patch.crates-io]` points those names here, so every gpui-fast crate comes from this one commit, next to `crates/gpui_windows` (already `gpui-fast-windows 0.1.14`). They are excluded from the workspace because they are not members of it.
